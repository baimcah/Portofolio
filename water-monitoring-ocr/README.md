# Water Usage Monitoring with OCR-Based Meter Reading

## 📌 Project Overview

Developed an automated water meter reading system using ESP32-CAM and Python OCR. 
System captures meter images, extracts readings via Optical Character Recognition, and logs data in real-time.

**Status:** Completed & Operational
**Location:** ASTRATech water monitoring system
**Duration:** 2 months

---

## 🎯 Problem Solved

- ❌ Manual meter reading → time-consuming & error-prone
- ❌ No real-time usage tracking
- ❌ Difficult to detect leaks or abnormal consumption
- ❌ No historical data for trend analysis

---

## ✅ Solution Implemented

| Component | Technology | Purpose |
|-----------|-----------|---------|
| **Camera** | ESP32-CAM | Automated image capture |
| **Processing** | Python + OCR | Digit extraction & recognition |
| **Backend** | Local server | Data processing & logging |
| **Storage** | Database | Historical data archival |
| **Monitoring** | Real-time dashboard | Usage trends & alerts |

---

## 📊 Results

- 📷 **99%+ OCR accuracy** in digit recognition
- ⚡ **Real-time monitoring** of water usage
- 📉 **Leak detection** via anomaly analysis
- 💾 **Complete audit trail** for consumption history
- 🤖 **Zero manual intervention** required

---

## 🔧 How It Works

1. **Image Capture** → ESP32-CAM photographs meter display
2. **Image Processing** → Python script processes image
3. **OCR Extraction** → Recognizes meter digits (0–9)
4. **Data Validation** → Checks reading consistency
5. **Logging** → Stores reading in database with timestamp
6. **Analysis** → Dashboard shows trends & alerts
