# SCADA-Based Automation System: Recycled Plastic Bottle Cap Manufacturing

## 📌 Project Overview

Developed a full SCADA system for automated recycling of plastic bottle caps into raw material at Politeknik Astra. System monitors 5+ sensors, controls 3 motor stages, and logs all data for compliance.

**Status:** Completed & Operational
**Duration:** 4 months (Jan–Apr 2025)
**Team:** 3 engineers

---

## 🎯 Problem Solved

- ❌ Manual process → time-consuming, inconsistent
- ❌ No safety monitoring → risk of equipment damage
- ❌ No data logging → can't trace production batches

---

## ✅ Solution Implemented

| Component | Technology | Purpose |
|-----------|-----------|---------|
| PLC Controller | Omron CP1E | Logic engine |
| HMI Interface | NB Designer | Real-time monitoring |
| Sensors (5+) | Temperature, Pressure, Level | Data acquisition |
| Motors (3x) | Conveyor, Mixer, Extruder | Automated stages |
| Database | Local logging | Batch tracking |

---

## 📊 Results

- ⚡ **80% faster** than manual process
- 📈 **99.2% accuracy** in batch tracking
- 🛡️ **5 safety interlocks** preventing operator error
- 📉 **40% energy savings** vs. previous method

---

## 🔧 How It Works

1. **Sensors** → Read material metrics (temp, level, pressure)
2. **PLC** → Execute control logic every 100ms
3. **Motors** → Activate/deactivate based on conditions
4. **HMI** → Display real-time status + alerts
5. **Database** → Log all events for audit trail

---

## 🚀 Key Learnings

- SCADA system design for industrial safety
- Multi-stage motor sequencing & interlocking
- Real-time data monitoring & alarming
- Troubleshooting under production constraints
