# Automatic Multi-System: Chicken Coop, Catfish Pond & Hydroponic Plant

## 📌 Project Overview

Developed an integrated automation system managing three agricultural/farming systems simultaneously:
chicken coop, catfish pond, and hydroponic garden. System monitors & controls temperature, humidity, 
water level, and feeding automatically.

**Status:** Completed & Operational
**Duration:** 3 months
**Scope:** Non-academic personal project (outside Politeknik Astra)

---

## 🎯 Problem Solved

- ❌ Manual management of 3 systems → time-consuming & inconsistent
- ❌ No real-time monitoring → risk of animal/plant loss
- ❌ Variable conditions → affects productivity & health
- ❌ Labor-intensive daily maintenance

---

## ✅ Solution Implemented

| System | Sensors | Actuators | Purpose |
|--------|---------|-----------|---------|
| **Chicken Coop** | Temp, humidity, door sensor | Fan, heater, auto-feeder | Optimal climate control |
| **Catfish Pond** | Water temp, pH, level, oxygen | Aerator, heater, pump | Ideal aquatic conditions |
| **Hydroponic** | Humidity, soil moisture, light | Watering pump, grow light | Optimal plant growth |

---

## 📊 Results

- 🌡️ **Temperature maintained** within ±2°C target
- 💧 **Water level auto-adjusted** preventing overflow/depletion
- 🍗 **Automated feeding** on schedule (chicken) + oxygen control (fish)
- 🌱 **Plant growth optimized** with automated irrigation
- ⏰ **24/7 autonomous operation** with minimal intervention

---

## 🔧 How It Works

**Chicken Coop Logic:**
1. Monitor temperature → activate/deactivate fan or heater
2. Humidity control via ventilation
3. Auto-feeder triggers on schedule
4. Door sensor prevents predator access

**Catfish Pond Logic:**
1. Monitor water temperature → control heater
2. Oxygen level → control aerator
3. Water level → auto-fill when low
4. pH monitoring for water quality

**Hydroponic System Logic:**
1. Soil moisture sensor → trigger watering pump
2. Humidity level → control ventilation
3. Light timer → automate grow light schedule
4. Nutrient level → alert for manual adjustment

---

## 🛠️ Tech Stack

- **Microcontroller:** Arduino/ESP32
- **Sensors:** 
  - Temperature (DHT22, DS18B20)
  - Humidity (DHT22)
  - Water level (capacitive)
  - pH (analog sensor)
  - Soil moisture (capacitive)
  - Light (LDR)
- **Actuators:**
  - Relay modules (fan, heater, pump, feeder)
  - Servo (door control)
  - DC motors (aerator)
- **Power:** Solar panel + battery system
