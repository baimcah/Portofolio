# Real-Time Electricity Consumption Monitoring System (IoT + Android)

## 📌 Project Overview

Developed a comprehensive IoT system for real-time electricity consumption monitoring with mobile visualization. 
System collects data from sensors, processes on Firebase, and displays analytics on Android app.

**Status:** Completed & Deployed
**Duration:** 3 months
**Platform:** IoT Sensors → Firebase → Android App

---

## 🎯 Problem Solved

- ❌ No real-time visibility into electricity usage
- ❌ Manual meter reading → time-consuming & inaccurate
- ❌ No historical data for consumption analysis
- ❌ No alerts for abnormal usage patterns

---

## ✅ Solution Implemented

| Component | Technology | Purpose |
|-----------|-----------|---------|
| **Sensor Node** | IoT Sensors, Microcontroller | Real-time electricity measurement |
| **Backend** | Firebase Realtime Database | Cloud data storage & sync |
| **Mobile App** | Android Studio | Real-time visualization & analytics |
| **Dashboard** | Interactive UI | Live graphs, historical trends, alerts |

---

## 📊 Results

- ⚡ **Real-time monitoring** with <500ms latency
- 📈 **Interactive dashboard** with live graphs & trends
- 🔔 **Alert system** for abnormal consumption
- 💾 **Historical data logging** for consumption analysis
- 📱 **Mobile-first** design with responsive UI

---

## 🔧 How It Works

1. **Data Collection** → Sensors measure electrical parameters
2. **Cloud Sync** → Data pushed to Firebase in real-time
3. **Mobile Processing** → App retrieves & visualizes data
4. **Analytics** → Dashboard shows trends & consumption patterns
5. **Alerts** → Notifications for high usage thresholds

---

## 🛠️ Tech Stack

- **Sensors:** Current sensors, voltage sensors
- **Backend:** Firebase Realtime Database
- **Mobile:** Android Studio, Java/Kotlin
- **Protocol:** Real-time sync via Firebase SDK
- **Visualization:** Graph libraries, interactive dashboards

- Android app development with real-time data handling
- UI/UX design for data visualization
- Cloud-based data persistence & analytics
