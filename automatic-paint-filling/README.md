# Automatic Paint Filling System with PLC & HMI

## 📌 Project Overview

Developed a precision automated paint filling system using PLC control and HMI interface. 
System ensures accurate volumetric filling, improved throughput, and enhanced worker safety.

**Status:** Completed & Operational
**Duration:** 2 months
**Controller:** Omron CP1E PLC

---

## 🎯 Problem Solved

- ❌ Manual filling → inconsistent volumes & spillage
- ❌ High labor cost & fatigue-related errors
- ❌ No standardization in fill quantity
- ❌ Safety hazards (chemical exposure)

---

## ✅ Solution Implemented

| Component | Technology | Purpose |
|-----------|-----------|---------|
| **PLC Controller** | Omron CP1E | Logic engine & sequence control |
| **HMI Interface** | NB Designer | Operator interface & monitoring |
| **Pump Control** | Precision solenoid | Accurate volumetric dispensing |
| **Sensors** | Level, pressure | Process feedback & validation |
| **Safety** | Interlocks & alarms | Worker protection |

---

## 📊 Results

- 🎯 **±2% accuracy** in fill volume
- ⚡ **3x faster** than manual process
- 📈 **100% consistency** across batches
- 🛡️ **Zero spillage** with precision control
- 👷 **Improved safety** with automated operation

---

## 🔧 How It Works

1. **Operator Input** → HMI sets desired fill volume
2. **PLC Sequence** → Executes filling program logic
3. **Pump Control** → Solenoid valve regulates flow rate
4. **Sensor Feedback** → Level sensor confirms fill completion
5. **Validation** → Pressure/weight sensor verifies accuracy
6. **Alert System** → HMI displays status & alarms

---

## 🛠️ Tech Stack

- **PLC:** Omron CP1E
- **Programming:** CX-Programmer (ladder logic)
- **HMI:** NB Designer software
- **I/O:** Digital input/output for control
- **Sensors:** Level, pressure, weight sensors
