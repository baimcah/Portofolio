# Queue Monitoring System with YOLOv11 AI

## 📌 Project Overview

Developed an AI-powered real-time queue monitoring system using YOLOv11 object detection. 
System detects crowd density, monitors queue conditions, and provides actionable analytics for service optimization.

**Status:** Completed & Operational
**Duration:** 2 months
**Tech:** YOLOv11, Node-RED, Real-time Detection

---

## 🎯 Problem Solved

- ❌ Manual queue monitoring → labor-intensive
- ❌ No real-time visibility into crowd density
- ❌ Unable to optimize service allocation
- ❌ No data for queue management decisions

---

## ✅ Solution Implemented

| Component | Technology | Purpose |
|-----------|-----------|---------|
| **AI Model** | YOLOv11 | Real-time person detection |
| **Processing** | Node-RED | Data pipeline & automation |
| **Communication** | MQTT | Real-time data streaming |
| **Monitoring** | Dashboard | Live queue visualization |

---

## 📊 Results

- 🎯 **99%+ detection accuracy** for crowd counting
- ⚡ **Real-time monitoring** (<100ms latency)
- 📉 **Queue analytics** (wait time trends, peak hours)
- 🎬 **Live feed** with annotated detection
- 📊 **Actionable insights** for service optimization

---

## 🔧 How It Works

1. **Camera Feed** → Continuous video stream
2. **YOLOv11 Detection** → Detects & counts people in real-time
3. **Data Processing** → Node-RED normalizes & analyzes data
4. **MQTT Publishing** → Streams data to subscribers
5. **Dashboard** → Real-time queue status & analytics

---

## 🛠️ Tech Stack

- **AI/CV:** YOLOv11, OpenCV, Python
- **Processing:** Node-RED, Python scripts
- **Communication:** MQTT broker
- **Visualization:** Real-time dashboard
- **Hardware:** USB/IP camera feed
